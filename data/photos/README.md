# data/photos/ — your image library

**Upload all your Ladies of Destiny images here** (GitHub web: *Add file → Upload files*, drag & drop, commit).

## How the agent uses them
- It posts **one image per day** at 10:00 EAT, in **random (shuffled) order** — not alphabetical, not upload order.
- **No image repeats** until every image has been used once — then the deck is **reshuffled** and a new random cycle begins, forever.
- Add new images any time — they join the current shuffled deck at a random position (they don't wait a full cycle).

## Rules
- **JPG or PNG** (PNG is auto-converted to JPG by the workflow; HEIC is not supported — convert HEIC to JPG on your phone/PC first).
- Any size/aspect ratio is fine — the workflow auto-crops to Instagram-safe proportions, rotates phone photos correctly and shrinks huge files.
- Filenames don't matter — the posting order is **random** (shuffled like a deck of cards), so keep whatever names your camera gives.
- While this folder is **empty**, the agent still posts the daily caption to Facebook (text-only) and waits for images to enable Instagram.
